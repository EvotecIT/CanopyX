## Where to begin

Start with [Getting started](/docs/getting-started/) if you write C#: it installs the package and builds a tree and a table you can open from disk. Start with [JavaScript](/docs/javascript/) if your page already has a front end. Then pick a [delivery mode](/docs/delivery/) for the size of your data, and keep the [data protocol](/docs/data-protocol/) at hand when your own server answers the requests.
