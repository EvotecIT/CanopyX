A matrix from a server table

The server writes the services by server as a plain table: row and column headers, a symbol and a state in every cell, and a link per probe that is the page without script. One call reads the states, the sites, the tiers and the links back from the table and turns it into the matrix, with groups, facets, search, only problems and the keyboard.

Click a cell: the page receives it (details: "host") with its row, column and link. Without that option the cell follows its link, as it does in the table. Use the button to put the table back.
