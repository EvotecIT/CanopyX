The data grid's face

The visual and interaction spec for the CanopyX flat grid in the Graphite look: tokens, toolbar, headers, rows, groups, cell presenters, column menu, filters, states, paging, status bar and the record drawer. Everything below is live HTML and CSS drawn from the proposed tokens; Codex ports it into the runtime and the reviewer compares the result against this page in both themes, at 1440 and 390 px.

01

Principles

  • Quiet chrome, loud data. Controls are outlined or ghost and secondary; colour is reserved for state, selection and the one primary action a host adds.
  • Healthy is quiet. Success never shouts: a small muted dot, muted bars. Danger and warning get full colour and weight (TestimoX D24).
  • One way to do each thing. Filter a column from its header; build complex filters in one builder; reset lives in Views; selection actions appear only while something is selected.
  • Numbers line up. Tabular figures, right-aligned numeric cells and their headers, units in the header not in every cell where possible.
  • Everything from tokens. No literal colours or sizes in the runtime CSS other than the token defaults; hosts theme by setting the inputs in 02.

Toolbar order: search (flex, 240–360 px, / focuses it), Filters (outlined; accent-soft with a count badge when filters are active), Columns and Views as ghost buttons; spacer; selection bar (only while rows are selected); separator; Export (ghost); overflow ⋯ for host actions, Record details, Print and Reset view. "Reset view" and "Saved views" both live in Views. Select page / select all matching move into the header checkbox menu.
  2. Result line: "9 of 214 domain controllers" using the host's noun (default "rows"), then removable chips, then "Clear all". Hidden when there is no search and no filter, so an untouched grid starts with the header.
  3. Grouping bar: only when grouping is enabled. Chips are draggable to reorder levels; the dashed target accepts a header drag and a keyboard "Group by this column" from the column menu.
  4. Header: 13 px bold in text-2, sentence case (long translated labels stay readable), numeric headers right-aligned with their cells. Sort arrow in accent after the label, with a superscript priority only when more than one column is sorted. A filled accent filter icon marks an active column filter. The column menu button appears on hover or focus (always visible on touch) and stays highlighted while its menu is open. Column separators are short 1 px lines inset 9 px.
  5. Rows: no zebra by default; 1 px row lines. Hover is a 4 % tint. Selection is accent 11 % plus a 2 px accent bar on the left. Row tone rules draw a 3 px tone bar on the left instead of tinting the whole row, so selection and tone can coexist. Keyboard focus is a 2 px accent outline inset in the cell.
  6. Group rows: group-bg, bold, chevron, label, muted count, aggregates in their own columns, worst state in the state column. Summary (pinned) row uses head-bg with a strong top line.
  7. Status bar: optional, 32 px, head-bg. Left: counts. Right: aggregates of the selected rows or cell range for numeric columns the host marks as aggregatable.
  8. Pinned columns: a strong 1 px edge and a soft 6 px shadow that appears only while the centre is scrolled.

Column menu and column filter

The header menu button opens the column menu; "Filter…" in it, or the filter icon, opens a popover anchored to that header for that column only. Filters apply live (debounced 200 ms); there is no Apply button.

Dates: Today, Yesterday, Last 7 days, Last 30 days, This month, or a range. Shown in the grid's time zone, with the zone named.

  • Popovers: 280 px (menu 244 px), radius 6, panel shadow, header with the column name and a muted count. On phones they become bottom sheets with a drag handle.

  • Joiner words ("and"/"or") sit in the left gutter of each condition after the first, so the logic reads as a sentence. Groups nest at most two levels in the UI (the engine allows eight; deeper saved filters display read-only with "Edit as text").

  • Loading: skeleton rows at the current row height, bar widths varied per column and right-aligned for numeric columns; shimmer stops under reduced motion. Appears after 150 ms so fast loads never flash. Loading more while scrolling shows skeletons only for the missing rows.

11

Acceptance for the implementation

  • Every example page in the CanopyX gallery matches this spec in light and dark at 1440 and 390 px; screenshots sit beside this page for review.
  • No literal colours in runtime CSS outside token defaults; existing --cx-* inputs keep working; host tones still map through --cx-tone-<name>.
  • Muted text and icons ≥ 4.5:1 (text) and ≥ 3:1 (icons, focus ring, checkbox borders) against surface, head-bg and selected-bg in both themes; axe passes; forced-colours keeps focus, selection and tone bars visible.
  • Runtime size budgets in docs/architecture.md still hold; the scroll benchmark at 4x CPU does not regress.
  • The static outline (print, email, Word) uses the same presenters' text forms: check and dash, pill text, state text, strip as a compact text summary.
